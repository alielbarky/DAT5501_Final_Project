This is a repository dedicated to the final project for DAT5501.
.
This project analyses TFL’s passenger income in real terms by adjusting historical revenues for inflation and extending them using forecast inflation. Multiple inflation models were tested and compared with real data to determine the most accurate model based on the lowest mean absolute value. An ARIMA model was determined to be the best and was therefore used to project inflation, informed by comparison with simpler polynomial models. The workflow produced figures to assess whether TfL’s real passenger income can be sustained under continued inflationary pressure for the next few years, data which can then be used to inform future action such as adjusting price within the right ranges or reducing costs of production to maintain revenue/profit.
